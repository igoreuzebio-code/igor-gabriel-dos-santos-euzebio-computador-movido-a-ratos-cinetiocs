Como usar o Negrito em HTML

O que é o negrito? (bold)

O negrito serve para destacar uma palavra ou frase no texto

Em HTML, usamos b para isso

Como escrever?

se faz assim

<b> texto aqui </b>

Exemplo simples

Este é um texto com a palavra negrito destacada.

Outro Exemplo

Você pode colocar qualquer parte do texto em negrito, não apenas uma palavra.

Lembre-se

Sempre feche com /b no final, senão todo o restante do texto ficará em negrito
